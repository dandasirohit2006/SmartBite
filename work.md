# SmartCanteen Project Work Summary

## What I built

I created a simple but polished three-page college canteen project structure for the SmartCanteen idea:

- Landing page: [index.html](index.html)
- Admin portal: [admin.html](admin.html)
- Student portal: [student.html](student.html)

## Design direction

- Warm beige, brown, and white palette to match a clean campus-canteen aesthetic
- Modern but simple layout with rounded cards and clean spacing
- Responsive layout for mobile, tablet, and desktop screens
- Strong emphasis on the student ordering flow and digital token concept
- Admin section kept separate so the college authority flow is clear

## Landing page

The landing page is designed as a strong product showcase for the project. It includes:

- Sticky navbar
- Student-centric hero section
- Smart queue and token concept
- Quick stats
- How-it-works section
- Smart feature cards
- Footer and CTAs

The admin button is placed in a small corner area, while the main student focus remains the central CTA.

## Admin portal

The admin page is built to communicate the authority-side workflow:

- College registration / signup form
- Admin login form
- Canteen and college data entry
- Daily menu and pricing management preview
- Real-time order status cards

This makes it easy for a beginner to understand how an authority would register their canteen and manage everyday operations.

## Student portal

The student page demonstrates the customer-side flow:

- Select college
- Select canteen
- Choose food item
- See pricing and estimated wait time
- Generate a digital token
- View order status as preparing or ready

This keeps all complex order flow off the landing page and moves it into a dedicated student experience page.

## Why this structure works

The project now follows a more realistic product flow:

1. Landing page introduces the product
2. Admin page handles college/canteen setup and management
3. Student page handles ordering and queue tracking

This makes the whole project easier for a newcomer to understand and much more realistic as a college project demo.

- Add authentication for admins and students
- Store menu items, college records, and orders in a database
